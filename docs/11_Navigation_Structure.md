# Document 11: Navigation Structure
## Project: Nursing Administration Portal
**Client:** Jazan Specialty Hospital (JSH)
**Phase:** 3 - Information Architecture
**Version:** 1.0

---

## 1. Overview (نظرة عامة)
This document details how users will navigate through the Nursing Administration Portal. The navigation must be intuitive, accessible, and optimized for both desktop and mobile devices.

## 2. Primary Navigation (القائمة الرئيسية)
The primary navigation will be present on all pages (Top Header on Desktop, Hamburger Menu/Bottom Bar on Mobile).

*   **Home (الرئيسية):** Returns to the Dashboard.
*   **Departments (الأقسام):** Dropdown menu listing clinical and operational departments.
*   **Quality & Policies (الجودة والسياسات):** Access to the Document Control Center.
*   **Governance (الحوكمة):** Access to Councils and Committees.
*   **Education (التعليم):** Access to training calendar and resources.
*   **Admin Panel (الإدارة):** Visible only to users with Admin or Manager roles.

## 3. Utility Navigation (قائمة الأدوات)
Located in the top-right corner of the header.

*   **Global Search (البحث):** Prominent search bar.
*   **Notifications (الإشعارات):** Bell icon with a badge for unread alerts.
*   **User Profile (الملف الشخصي):** Avatar icon providing access to profile settings and logout.

## 4. Secondary Navigation (القائمة الفرعية)
Used within specific modules to navigate sub-sections.

*   **Example: Inside a Department Page**
    *   Overview (نظرة عامة)
    *   Schedule (الجدول)
    *   Staff (الموظفون)
    *   Metrics (المؤشرات)

## 5. Mobile Navigation Strategy (استراتيجية تصفح الجوال)
*   **Bottom Navigation Bar:** For the most frequent actions (Home, Search, Notifications, Profile) to ensure thumb reachability.
*   **Hamburger Menu (Off-canvas):** For accessing the full primary navigation (Departments, Governance, Education) without cluttering the small screen.
