# Document 13: Taxonomy
## Project: Nursing Administration Portal
**Client:** Jazan Specialty Hospital (JSH)
**Phase:** 3 - Information Architecture
**Version:** 1.0

---

## 1. Overview (نظرة عامة)
This document outlines the classification system (Taxonomy) used to organize documents and content within the portal. A robust taxonomy ensures that the Global Search function returns accurate results.

## 2. Document Categories (فئات الوثائق)
All files uploaded to the Document Control Center must be tagged with at least one category:
*   **APP (Administrative Policies & Procedures)**
*   **CPP (Clinical Policies & Procedures)**
*   **CPG (Clinical Practice Guidelines)**
*   **FRM (Standard Forms)**
*   **MAN (Manuals & Handbooks)**

## 3. Departmental Tags (أوسمة الأقسام)
Tags representing the hospital's organizational structure:
*   ER (Emergency Room)
*   ICU (Intensive Care Unit)
*   NICU (Neonatal ICU)
*   OR (Operating Rooms)
*   OPD (Outpatient Department)
*   Maternity (OB/GYN)
*   General Wards (Medical/Surgical)

## 4. Status Tags (أوسمة الحالة)
System-applied tags to define the lifecycle stage:
*   Draft
*   Pending Approval
*   Published / Active
*   Expired
*   Archived

## 5. Tagging Rules (قواعد التصنيف)
*   A document must have exactly one Document Category.
*   A document can have multiple Departmental Tags (e.g., a policy relevant to both ER and ICU).
*   If a document applies to the entire hospital, it receives the "General/Hospital-wide" tag instead of specific department tags.
